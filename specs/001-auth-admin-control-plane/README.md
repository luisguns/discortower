# Spec 001 — Índice

Esta especificação segue um fluxo SDD: requisitos aprovados orientam o design; o design aprovado orienta as tarefas; código só é produzido depois dessas duas aprovações.

1. [`requirements.md`](requirements.md) — comportamento, limites e critérios de aceite.
2. [`design.md`](design.md) — arquitetura, dados, segurança e integração com o app atual.
3. [`tasks.md`](tasks.md) — sequência de implementação e gates de verificação.

Status atual: **proposta aguardando aprovação do proprietário**.

Alterações de escopo devem começar em `requirements.md`. Decisões técnicas que não mudam comportamento pertencem a `design.md`. A execução e o progresso pertencem a `tasks.md`.
